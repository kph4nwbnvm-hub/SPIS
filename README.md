# النبض الرقمي للموانئ — SPIS (النسخة العامة v9.3)

نموذجٌ أولي تفاعلي — **كل الأرقام في هذه النسخة محاكاة**.
بيانات الخلية الأولى الفعلية مضمّنة **مشفّرة** (AES-GCM-256) ولا تُفتح إلا بعبارة مرور من ⚙ الإعدادات، ولجلسة المتصفح الحالية فقط.

- يعمل في المتصفح بلا أي اتصال بجهة خارجية، ويُثبَّت على الجوال من «إضافة إلى الشاشة الرئيسية».
- الشيفرة معمّاة ومغلّفة.

صاحب الفكرة: م. نائف خالد سعد الفران.
